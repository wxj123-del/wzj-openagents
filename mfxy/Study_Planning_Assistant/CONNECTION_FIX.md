# 🔧 数字人连接问题修复说明

## 问题原因

SDK错误码10005：**房间限流，请关闭之前的房间后再连接**

这是因为：
1. 之前的数字人连接没有正确断开
2. 存在多个SDK实例同时运行
3. 容器中残留了旧的SDK内容

## ✅ 已修复的内容

### 1. **自动清理旧连接**
- 连接前自动检测并断开旧连接
- 清理旧的SDK实例
- 清空容器内容

### 2. **优化断开连接流程**
- 确保SDK实例完全销毁
- 清空容器DOM
- 重置所有状态标志

### 3. **增强错误处理**
- try-catch包裹所有清理操作
- 确保即使出错也能重置状态

## 🚀 使用方法

### 第一次连接
1. 刷新页面（Ctrl+R）
2. 点击"连接数字人"
3. 等待加载完成

### 重新连接
**方式1：手动断开后再连接**
1. 点击"断开连接"按钮
2. 等待1-2秒
3. 再次点击"连接数字人"

**方式2：直接点击"连接数字人"**
- 系统会自动检测并断开旧连接
- 自动清理后重新连接

## ⚠️ 如果还有问题

### 问题1: 还是一直显示限流错误

**解决方案：**
1. 完全刷新页面（Ctrl+Shift+R 强制刷新）
2. 清除浏览器缓存
3. 或者等待1-2分钟后再试

### 问题2: 数字人不显示

**检查清单：**
- [ ] 控制台显示"已连接"
- [ ] 没有红色错误信息
- [ ] 容器尺寸大于0（查看日志中的offsetWidth和offsetHeight）
- [ ] 网络连接正常

### 问题3: 连接后立即断开

**可能原因：**
- 密钥无效或过期
- 账户余额不足
- 同时有多个标签页在连接

**解决方案：**
- 确保只在一个标签页使用
- 检查密钥是否有效
- 访问魔珐星云平台确认账户状态

## 💡 最佳实践

### ✅ 推荐做法
1. 使用完记得断开连接
2. 不要同时在多个标签页连接
3. 定期刷新页面清理状态
4. 出现问题时先完全刷新页面

### ❌ 避免做法
1. 频繁快速地点击连接/断开
2. 不断开就刷新页面
3. 同时在多个窗口使用
4. 忽略错误提示继续操作
