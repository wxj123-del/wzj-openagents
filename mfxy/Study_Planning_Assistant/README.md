# 📚 AI学习规划助手

> 基于魔珐星云3D数字人和魔搭社区AI的智能学习规划助手

## 🌟 项目简介

AI学习规划助手是一个参加**魔珐星云具身智能黑客松**的作品，属于**AI实时交互教育赛道**的学习规划(督学)方向。

本项目通过3D数字人形象，为学生提供：
- ✅ 个性化学习计划制定
- ✅ 学习进度追踪
- ✅ 智能督促与激励
- ✅ 实时互动问答

## 🎯 核心功能

### 1. 数字人交互
- 3D数字人实时渲染与驱动
- 自然的语音表达和口型同步
- 多状态行为控制(倾听/思考/说话/待机)

### 2. AI学习规划
- 通过对话了解学生情况
- 制定个性化学习计划
- 提供学习方法和建议

### 3. 学习督促
- 学习提醒功能
- 进度追踪与反馈
- 智能鼓励与激励

### 4. 密钥管理
- 支持内置测试密钥
- 支持自定义密钥配置
- LocalStorage持久化存储

## 🛠️ 技术栈

- **前端**: 原生HTML/CSS/JavaScript (单页面应用)
- **数字人SDK**: 魔珐星云具身驱动SDK v0.1.0-alpha.72
- **AI模型**: 魔搭社区API
- **数据存储**: localStorage

## 🚀 快速开始

### 1. 环境要求

- 现代浏览器(Chrome/Edge/Firefox)
- 本地开发环境(localhost)或HTTPS环境

**注意**: 魔珐星云SDK要求在HTTPS或localhost环境下运行

### 2. 本地运行

#### 方法1: 使用Python
```bash
# 在项目目录下运行
python -m http.server 8000

# 访问 http://localhost:8000
```

#### 方法2: 使用Node.js
```bash
# 安装serve
npm install -g serve

# 启动服务
serve

# 访问 http://localhost:3000
```

#### 方法3: 使用PHP
```bash
# 在项目目录下运行
php -S localhost:8000

# 访问 http://localhost:8000
```

### 3. 使用步骤

1. **打开页面**: 浏览器访问 `http://localhost:8000`

2. **配置密钥** (可选):
   - 点击右上角"密钥设置"
   - 勾选"使用内置测试密钥"使用默认密钥
   - 或取消勾选并输入自己的密钥

3. **连接数字人**:
   - 点击"连接数字人"按钮
   - 等待数字人初始化完成
   - 看到"已连接"状态即可使用

4. **开始使用**:
   - 在输入框输入消息,点击"发送"
   - 或使用快速操作按钮:
     - 📝 制定学习计划
     - 📊 查看进度
     - ⏰ 学习提醒

## ⚙️ 配置说明

### 数字人状态

| 状态 | 说明 |
|------|------|
| offlineMode | 离线模式(不消耗积分) |
| onlineMode | 在线模式 |
| idle | 待机等待 |
| listen | 倾听状态 |
| think | 思考状态 |
| speak | 说话状态 |

### 积分消耗优化

1. 调试时使用基础音色
2. 长时间无交互时自动切换到离线模式
3. 合理控制数字人说话频率

## 🐛 常见问题

### Q: 数字人无法连接?
A: 请检查:
1. 是否在HTTPS或localhost环境下运行
2. 密钥是否正确配置
3. 网络连接是否正常
4. 浏览器控制台是否有错误信息

### Q: AI没有回复?
A: 请检查:
1. 魔搭社区API Key是否有效
2. 是否有剩余API调用额度
3. 网络连接是否正常

### Q: 数字人不说话?
A: 请检查:
1. 浏览器是否允许自动播放音频
2. 音量是否开启
3. SDK是否正确加载

### Q: 如何重置所有数据?
A: 在浏览器控制台执行:
```javascript
localStorage.clear();
location.reload();
```
