# AI学习规划助手 - 开发文档

## 1. 项目概述

### 1.1 项目简介
基于魔珐星云3D数字人技术，结合魔搭社区AI模型，打造一个智能学习规划助手。通过数字人形象，为学生提供个性化学习计划制定、学习进度追踪、学习督促和鼓励等功能。

### 1.2 参赛信息
- **黑客松**: 魔珐星云具身智能黑客松
- **赛道**: AI实时交互教育赛道
- **方向**: 学习规划（督学）
- **时间**: 2025/12/18 - 2026/1/31

### 1.3 核心价值
- 让AI拥有"老师的身体与对话能力"，把学习从"看内容"升级为能实时对话、能引导学习、能陪练的AI老师
- 定制学习计划，实时追踪与鼓励
- 提供沉浸式1对1的学习体验

## 2. 技术栈

### 2.1 前端技术
- **框架**: 原生HTML/CSS/JavaScript (单页面应用)
- **数字人SDK**: 魔珐星云具身驱动SDK (JS版本) v0.1.0-alpha.72
- **AI模型**: 魔搭社区API
- **数据存储**: localStorage
- **样式**: CSS3 (支持响应式设计)
- **构建工具**: 无需构建工具，纯前端实现

### 2.2 外部依赖
- 魔珐星云SDK: `https://media.xingyun3d.com/xingyun3d/general/litesdk/xmovAvatar@latest.js`
- 魔搭社区API: 待定

## 3. 功能设计

### 3.1 核心功能模块

#### 3.1.1 密钥管理模块
- **功能**: 管理API密钥和数字人密钥
- **存储位置**: localStorage
- **密钥类型**:
  - xingyun_appId: '65254e14e816423da6218e47b2003ea8',
  xingyun_appSecret: 'ba0cb4a582e045d382fd65468937886f',
  modelscope_api_key: 'ms-6e0d45c0-1a56-4527-8ddc-fd7cb1dd796b'
- **特性**:
  - 提供内置测试密钥
  - 支持用户手动输入自定义密钥
  - 密钥持久化存储
  - 密钥验证功能

#### 3.1.2 数字人连接控制模块
- **功能**: 控制数字人的连接与断开
- **控制方式**:
  - 连接按钮: 初始化SDK并建立连接
  - 断开按钮: 销毁SDK实例并释放资源
- **状态显示**:
  - 未连接
  - 连接中
  - 已连接
  - 连接失败

#### 3.1.3 学习计划制定模块
- **功能**: 基于学生情况，AI制定个性化学习计划
- **交互流程**:
  1. 数字人询问学生基本信息(年级、科目、学习目标等)
  2. 学生通过文本输入回答
  3. AI分析并生成学习计划
  4. 数字人展示学习计划并讲解
- **AI能力**:
  - 理解学生需求
  - 制定合理学习计划
  - 提供学习建议

#### 3.1.4 学习进度追踪模块
- **功能**: 记录和展示学习进度
- **数据项**:
  - 每日学习时长
  - 完成任务数
  - 学习效果评估
- **展示方式**:
  - 数字人口播
  - Widget组件可视化展示

#### 3.1.5 学习督促与激励模块
- **功能**: 定期提醒和鼓励学生
- **场景**:
  - 每日学习提醒
  - 学习进度反馈
  - 达成目标祝贺
  - 学习倦怠期鼓励
- **数字人状态**:
  - listen: 倾听学生反馈
  - think: 思考建议
  - speak: 提供鼓励和建议

#### 3.1.6 互动问答模块
- **功能**: 学生可以随时向数字人提问
- **支持场景**:
  - 学习方法咨询
  - 知识点疑问
  - 计划调整建议
- **交互方式**: 文本输入 + 数字人语音回复

### 3.2 数字人状态设计

| 状态 | 说明 | 使用场景 |
|------|------|----------|
| offlineMode | 离线模式，不消耗积分 | 长时间无交互时 |
| onlineMode | 在线模式 | 用户开始使用时 |
| idle | 待机等待 | 初始化完成，等待用户输入 |
| interactive_idle | 待机互动 | 交互状态前的循环 |
| listen | 倾听 | 接收用户输入时 |
| think | 思考 | AI分析问题时 |
| speak | 说话 | 数字人回复时 |

### 3.3 交互流程示例

**场景: 制定学习计划**

```
1. 用户点击"制定学习计划"
   -> 数字人: listen状态

2. 数字人: "你好！我是你的学习规划助手。请问你现在是几年级呢？"
   -> 数字人: speak状态

3. 用户输入: "我上高二"
   -> 发送到魔搭AI

4. AI分析并生成下一问题
   -> 数字人: think状态

5. 数字人: "好的，高二正是关键时期。你想重点提升哪几科呢？"
   -> 数字人: speak状态

6. ... 继续对话收集信息 ...

7. AI生成完整学习计划
   -> 数字人展示计划(使用Widget组件)
   -> 数字人讲解计划细节
```

## 9. 技术要点

### 9.1 数字人状态管理
- 合理使用 listen/think/speak 状态切换
- 流式调用speak方法时正确控制 is_start 和 is_end
- 监听 onVoiceStateChange 事件管理音频播放

### 9.2 流式响应处理
```javascript
// 示例代码
let isFirstChunk = true;
let isComplete = false;

for await (const chunk of aiStreamResponse) {
  const text = chunk.content;
  avatarSDK.speak(text, isFirstChunk, isComplete);
  isFirstChunk = false;
}

// 最后一次调用
isComplete = true;
avatarSDK.speak('', false, true);
```

### 9.3 积分消耗优化
- 使用基础音色进行调试
- 长时间无交互时切换到离线模式
- 合理控制数字人说话频率

### 9.4 错误处理
- 网络错误: 提示用户检查网络
- 密钥错误: 引导用户重新输入
- SDK错误: 记录日志并提供重试选项
- AI调用失败: 降级到预设回复
