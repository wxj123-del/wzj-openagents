# 数字人无法显示 - 彻底解决方案

## 问题原因

数字人SDK的会话限流(错误代码10005)是**服务器端的限制**,无法通过代码绕过。

### 为什么会限流?

星云数字人SDK对每个App ID有同时会话数限制:
- 免费版通常只允许1-2个并发会话
- 如果之前的会话没有正确关闭,新连接会被拒绝
- 会话通常需要10-15分钟才能自动过期

## 彻底的解决方案

### 方案1: 等待会话过期(最简单)

**步骤:**
1. 等待10-15分钟
2. 刷新浏览器
3. 点击"连接数字人"

**优点:** 无需任何操作
**缺点:** 需要等待

### 方案2: 使用新的App ID(推荐)

**步骤:**
1. 访问星云官网: https://xingyun3d.com
2. 注册新账号(或使用不同邮箱)
3. 创建新应用,获取新的App ID和Secret
4. 在首页"设置"中配置新的密钥
5. 点击"连接数字人"

**优点:** 立即可用
**缺点:** 需要注册新账号

### 方案3: 仅使用AI占卜功能(最实用)

**重要提示:**
- **AI占卜功能完全可用!** 不依赖数字人
- 塔罗占卜、星座运势都能正常工作
- 只是少了数字人的语音和视觉呈现

**使用方法:**
1. 配置魔搭API密钥(测试密钥已内置)
2. 直接使用塔罗占卜或星座运势
3. AI会在文本框中显示解读结果

### 验证数字人连接

如果想继续尝试数字人连接:

1. 打开浏览器控制台(F12)
2. 切换到Console标签
3. 点击"连接数字人"
4. 观察日志输出:
   ```
   加载SDK...
   创建SDK实例...
   初始化SDK...
   ```

5. 如果看到错误信息,查看类型:
   - `10005` → 会话限流,需等待或使用新App ID
   - `10001` → 容器不存在,刷新页面
   - 其他错误 → 检查密钥配置
